# Contribuir

## Alta de una categoría

1. Comprueba que no exista una categoría equivalente.
2. Asigna un identificador `C###` que no se haya utilizado.
3. Relaciónala con un dominio existente.
4. Describe el objetivo sin lenguaje comercial.
5. Añade proveedores representativos y una fuente verificable.
6. Abre un pull request explicando el cambio.

## Alta de un proveedor

Incluye nombre comercial, categorías aplicables, fuente oficial y estado de validación. No se aceptan clasificaciones basadas únicamente en material promocional.

## Criterios de calidad

- Evidencia verificable.
- Neutralidad tecnológica.
- Nombres y taxonomía consistentes.
- Ausencia de duplicidades.
- Fecha de revisión cuando se trate de información volátil.
